# Finanzas

App personal para controlar sueldo, ingresos, gastos fijos, tarjetas de crédito y cuotas. Se instala en el celular y se usa también desde la PC, con los mismos datos.

- **Puesta en marcha:** [docs/SETUP.md](docs/SETUP.md)
- **Diseño y plan por etapas:** [docs/DISENO.md](docs/DISENO.md)
- **Prototipo original:** [prototipo/index.html](prototipo/index.html)

## Estado

| Etapa | Contenido | Estado |
|---|---|---|
| 1 | Login, tópicos, medios de pago, movimientos, cuotas, Inicio, instalable | Hecha |
| 2 | Resúmenes de tarjeta, cierre de mes, gastos fijos | Pendiente |
| 3 | Notificaciones push y Google Calendar | Pendiente |
| 4 | Escaneo de tickets (OCR + IA) | Pendiente |
| 5 | Gráficos históricos, exportar a Excel, aguinaldo | Pendiente |

Stack: React + TypeScript + Vite (PWA) y Supabase.
